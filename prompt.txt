# Task: Add Optional Image Proxy Support to MirrorInKomik

## Objective
Tambahkan dukungan **Image Proxy** pada ekstensi `src/id/mirrorinkomik` dengan mengikuti implementasi yang sudah ada di `src/id/cgbum`.

## Requirements

- Implementasikan dukungan Image Proxy pada `src/id/mirrorinkomik`.
- Gunakan `src/id/cgbum` sebagai referensi implementasi.
- Image Proxy **bersifat opsional** dan hanya digunakan jika pengguna telah mengisi/mengaktifkan nilai Image Proxy di pengaturan.
- Jika Image Proxy tidak disetel, gambar harus tetap dimuat menggunakan URL asli seperti sebelumnya.
- Jangan mengubah fitur lain yang sudah berjalan.

## Testing

- Jalankan `./gradlew spotlessApply`.
- Pastikan:
  - Gambar dimuat melalui Image Proxy jika pengguna mengisinya.
  - Gambar tetap dimuat normal jika Image Proxy tidak disetel.
  - Tidak ada regresi pada fitur yang sudah ada.
