## Technical Requirements for `STRUKTUR.md`

File `STRUKTUR.md` yang dihasilkan HARUS memuat bagian-bagian berikut dengan jelas dan terstruktur:

### 1. Struktur Folder & Proyek (`Project Structure`)
* Gambarkan pohon direktori (directory tree) utama repositori ini (misalnya: `src/`, `lib/`, `gradle/`, `.github/`, dll.).
* Jelaskan struktur penamaan dan lokasi *source code* ekstensi per bahasa/region (khususnya fokus pada pola direktori seperti `src/id/<extension-name>`).
* Jelaskan fungsi dari folder-folder penting dan file konfigurasinya.

### 2. Arsitektur & Anatomi Ekstensi (`Extension Anatomy`)
* Jelaskan komponen utama dalam pembuatan satu ekstensi (class utama yang meng-extend `HttpSource` atau `ParsedHttpSource`, factory class jika ada multi-source, dsb.).
* Rangkum metode-metode utama yang wajib diimplementasikan/overridden oleh ekstensi (contoh: `popularMangaRequest`, `latestUpdatesParse`, `mangaDetailsParse`, `chapterListParse`, `pageListParse`, `imageRequest`).
* Jelaskan mekanisme HTTP Client & Network Interceptor (OkHttp, `CookieJar`, headers handling) yang umum digunakan di project ini.

### 3. Sistem Build & Gradle (`Build System & Commands`)
* Jelaskan cara kerja sistem *build* di project ini (Gradle Multi-Project/Module setup).
* Rangkum perintah-perintah penting yang sering digunakan untuk pengembangan, antara lain:
  * Cara build ekstensi tertentu atau seluruh ekstensi (`./gradlew assembleDebug`, dll.).
  * Cara menjalankan linter dan formatting kode (`./gradlew spotlessApply`, `./gradlew spotlessCheck`).
  * Cara menjalankan automated testing (`./gradlew testDebugUnitTest`).

### 4. Plugin, Dependensi & Tooling (`Plugins & Dependencies`)
* Identifikasi dan rangkum plugin Gradle utama yang dipakai dalam proyek ini (misalnya Android Gradle Plugin, Kotlin, Spotless, atau plugin kustom khusus Mihon/Tachiyomi).
* Rangkum dependensi utama (seperti Jsoup, OkHttp, kotlinx-serialization, dsb.) beserta fungsinya.
* Jelaskan konfigurasi CI/CD atau workflow (seperti GitHub Actions) jika relevan untuk proses pengecekan atau build otomatis.
